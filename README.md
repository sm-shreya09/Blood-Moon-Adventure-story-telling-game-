# 🌙 Blood Moon Adventure

An interactive browser-based text adventure game built using **HTML, CSS, and JavaScript**. Players can explore different story genres, make choices, and experience multiple endings based on their decisions.

## 📖 Overview

Blood Moon Adventure is a choice-driven storytelling game that offers immersive adventures across multiple genres. Each decision influences the storyline, leading to unique outcomes and endings.

The project demonstrates front-end web development concepts including:
- Interactive user interfaces
- Dynamic content rendering
- DOM manipulation
- Event handling
- Responsive design
- Story branching logic

## 🎯 Gameplay

1. Choose one of the available adventure genres.
2. Read the story carefully.
3. Select from the available choices.
4. Progress through different story paths.
5. Reach one of several unique endings.
6. Restart or return to the home screen.

---

## 🧩 Story Genres

### 🧙 Fantasy Quest
Embark on a magical journey to stop the Dark Sorcerer Zargoth and save Eldoria.

### 🚀 Sci-Fi Survival
Survive on the hostile alien planet Xerion-7 after a starship crash.

### 🕵 Mystery Detective
Investigate the disappearance of the legendary Jade Dragon artifact.

### 👻 Horror Night
Navigate a terrifying night under the Blood Moon and uncover the secrets of a haunted mansion.
